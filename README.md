# La memoria sumergida

Sitio web de pantalla completa para mostrar el StoryMapJS original de **La memoria sumergida** sin contenido adicional.

## Desarrollo local

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático.

## Publicar en Vercel

Importa este repositorio en Vercel. La configuración recomendada es:

- **Framework Preset:** Other
- **Root Directory:** `./`
- **Build Command:** dejar vacío
- **Output Directory:** `.`

Vercel servirá `index.html` directamente; no se necesita instalar dependencias ni configurar un proceso de compilación. El mapa se carga desde StoryMapJS y requiere conexión a internet. Web Analytics de Vercel se integra mediante su script HTML y debe estar habilitado en la configuración del proyecto de Vercel.
